# JSON Schema Viewer Logos

This directory contains different variations of the JSON Schema Viewer logo for different use cases:

- `logo-blue.svg` - The primary logo with Atlassian blue (#0052CC)
- `logo-black.svg` - Black monochrome version for light backgrounds
- `logo-white.svg` - White monochrome version for dark backgrounds

## Usage Guidelines

- Use `logo-blue.svg` as the default logo in most cases
- Use `logo-black.svg` when a monochrome version is needed on light backgrounds
- Use `logo-white.svg` when placing the logo on dark backgrounds

All logos are in SVG format for optimal scalability and quality at any size.
